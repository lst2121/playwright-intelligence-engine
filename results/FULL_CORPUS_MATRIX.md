### 3. Real-World Failure Modes Encountered
1. **Interactive Flag Ingestion (`pw:ui`):**
   - The CLI runner initially selected `pw:ui` (`playwright test --ui`) from `package.json`, which launched an interactive GUI server instead of running headless. Fixed by prioritizing headless scripts (`test:e2e`, `test:smoke`, `test:sanity`, `test`) and banning `--ui`.
2. **Multi-Browser Project Assumption:**
   - Repositories configure `chromium`, `firefox`, and `webkit` by default in `playwright.config.ts`. On systems where only Chromium binaries are downloaded, full-suite runs report browser launch errors for missing firefox/webkit binaries. PIE should optionally support `--project=chromium` filtering when running baseline checks.
3. **Monorepo Root Ambiguity:**
   - In monorepos (`twenty`, `hi.events`, `documenso`), the root `package.json` often lacks a `test:e2e` script or delegates via turbo/lerna, while the actual Playwright tests live in nested packages (`packages/twenty-e2e-testing`, `e2e/`, `packages/app-tests`). PIE's inspection correctly locates nested configs, but execution must target the specific subproject root.
